Privacy Policy

Last updated: November 10, 2026

Bricked Era is a documentary production project previously named Byte Stories. Its private, self-hosted application, previously named Byte Stories Studio, is used only by the owner to manage their own channel. It is not available to the public.

What data the app accesses

With the owner's permission (Google OAuth), the app uses YouTube API Services to upload videos, set thumbnails and captions, add videos to playlists, read the upload status of the owner's videos, and read the owner's channel analytics.

How data is stored

OAuth tokens and analytics data are stored only on the owner's own computer, with the tokens encrypted. No data is sold, shared with third parties, or used for advertising.

Third-party services

The app uses YouTube API Services. By using it, you are also bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. When access is revoked, the stored tokens stop working and can be deleted from the app.

Contact

For privacy questions or requests to delete locally stored account data, contact ivantrubin27@gmail.com.

TikTok integration

The optional TikTok connection uses Login Kit and the Content Posting API. With the owner's authorization, the application receives the account identifier, granted permissions, access and refresh tokens, and creator profile and posting-limit information. It sends the selected video, caption, visibility, interaction and disclosure choices to TikTok only after the owner requests that upload.

Account tokens are encrypted on the owner's computer and retained until disconnected or deleted. Upload receipts, account identifiers and post status are stored locally with the video project until the owner deletes them. This public website does not store TikTok tokens. The HTTPS return page temporarily handles the one-time authorization code in the browser and returns it to the local application for server-side exchange; it does not contain the client secret.

The Disconnect button requests token revocation from TikTok and deletes local tokens after successful revocation. The owner may request deletion of locally retained account and upload records through the contact below; deleting local records does not delete videos already posted to TikTok. TikTok processes uploaded content and account activity under its own privacy policy and terms.

This public website

This informational website is hosted on GitHub Pages. It contains no account connection form and no production dashboard. GitHub may process visitor connection data under the GitHub Privacy Statement.
